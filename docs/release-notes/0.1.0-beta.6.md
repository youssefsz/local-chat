Adds the installed version in Settings, Check for Updates in Settings and the macOS app menu, quiet daily checks, beta/stable channels, release notes, verified downloads and Restart to update. Drafts are saved before restart; downloaded updates remain available after quitting. Chat stays usable offline.

Update packages are signed separately from Apple code signing and bind the signature to the announced version. macOS remains Developer ID signed and notarized. Windows remains unsigned. Linux AppImage updates install in the app; Debian installations use downloaded packages.

Users of beta.5 and earlier need to install this release manually once to enable future in-app updates.
