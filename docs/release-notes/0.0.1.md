The first public Local Chat release. Share text, links, and code in public rooms with nearby computers on the same local network, without accounts or a separately installed server.

Includes automatic discovery, encrypted peer connections, local history and search, room drafts, exact code copying, Light/Dark/System appearance, background notifications, Reconnect controls, and signed in-app update packages.

Adds the official website, getting started guide, privacy policy, terms, and latest stable downloads at https://local-chat.youssef.tn. Website and policy links are available in Settings and the native Help menu.

Earlier test releases used 0.1.0-beta versions. Install 0.0.1 manually and choose the Stable update channel. The version reset does not bypass updater downgrade protection. Saved conversations stay in the same app data folder.
