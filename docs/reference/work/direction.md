# Nearby interface direction

Code-led desktop product prototype. Existing conversation supplies confirmed interview answers. User explicitly delegates the recommended visual design and requests the HTML now; no further approval round is needed.

Candidates considered: precision Swiss index; shared library; warm studio stationery; contemporary utility; soft ink notebook; quiet communal studio; dark editorial workspace. The concept-seed assigned candidate six, a quiet communal studio. It suits long reading sessions and sharing among a small group. Catalog challengers are declined for this requested minimal application; retain alignment discipline, legible status, stable row identity, and responsive prioritization without importing their decorative forms.

First viewport: full-height two-pane desktop application with pale warm sidebar, white message pane, compact room header, left-aligned messages, dark code block, bottom composer, and people online. Terracotta indicates active room and send action. Colored initials distinguish authors without photographic assets. Main message column has controlled reading width. A small top label identifies sample data.

Signature interaction: copy controls become checkmarked confirmations in place; keyboard room switching is immediate; search opens without animation. Long messages preserve whitespace and exact copying. New rooms and messages persist locally. Each room retains its draft. Sidebar becomes a navigation drawer on narrow widths. Optional people panel and theme settings are functional.

No cloud publication. No actual LAN discovery; network and participant content is sample data. No simulated delivery to real users. New messages are saved to the browser only and labeled accordingly.

Validation: 1440x900, 1024x768, and 390x844; current in-app width; room switching, creation, author-only management, search, message sending, code copy, draft persistence, settings, keyboard and mobile navigation. Two bounded visual inspection rounds.
