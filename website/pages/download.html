Windows

x64 · Intel and AMD
Windows 10 or later

Download for Windows

Currently unsigned. SmartScreen may warn.

How to install

Run the downloaded installer. Windows may show an unrecognized-app warning because this release is not Authenticode signed. Check that you downloaded it from this site or our GitHub repository.

Windows ARM is not supported. WebView2 is required; the installer can download it when needed.

Linux

x64 · Intel and AMD
AppImage or Debian package

Download AppImage

Download .deb instead

How to install

Make the AppImage executable using your file manager, then open it. Your distribution may need FUSE support. The .deb package is for compatible Debian and Ubuntu systems.

Linux ARM is not supported. A current WebKitGTK 4.1 runtime is required.

A few things to know.

These are early releases. macOS is locally exercised; physical Windows and Linux desktop, cross-device LAN, and update installation verification remain pending. See platform status.

Download buttons always resolve the latest published stable release on GitHub. If release information is unavailable, they take you to GitHub’s release page.

Coming from a beta?

The first public release is numbered 0.0.1. Earlier test builds used 0.1.0-beta versions, which sort higher. Install 0.0.1 manually, then choose the Stable update channel in Settings. Saved conversations stay in the same app data folder. The updater never forces a downgrade.

Updates after that.

Open Settings and choose Check for updates. macOS, Windows, and Linux AppImage can download and verify update packages in the app. You choose when to restart. Debian installations use downloaded packages.
