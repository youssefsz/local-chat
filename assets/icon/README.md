# Local Chat icon

`generated-concept.png` is the ImageGen concept. `master.svg` is an editable geometric redraw, not an embedded bitmap. `master.png` is the 1024px production raster. `tray.svg` is the monochrome menu-bar master; `src-tauri/icons/tray.png` is its template raster. Tauri's icon generator creates macOS ICNS, Windows ICO, and Linux PNG assets from master.svg.

Generation prompt:

Create one restrained flat desktop application icon concept for Local Chat, a utility for sharing messages between nearby computers. A balanced pair of overlapping conversation bubbles, only two bold geometric shapes, warm terracotta #a94329 with warm ivory #f5f4f0, clear silhouette at 16 pixels. Center the mark generously within a square warm ivory field. No lettering, gradients, glossy effects, mascots, shadows, tiny network diagrams, decorative detail, mockups or multiple variants. This is a production app icon concept, crisp flat vector-like geometry.

The vector redraw removes the generated image's slight texture and makes all small-size exports deterministic. One concept was generated; its conversation silhouette was selected without a second exploration round.
